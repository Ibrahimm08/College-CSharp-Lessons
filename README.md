# College-CSharp-Lessons
C# Windows Forms App (.NET Framework) projects from lessons during my T-Level course

## SQL in c#

These projects demonstrate a complete SQL CRUD system. It connects to a relational database and supports creating, reading, updating, and deleting records through a user interface. The projects include stored procedures to carry out database interactions.
